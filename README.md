# Xbox Game Pass Sales Dashboard

Este projeto foi desenvolvido como parte do curso de Análise de Dados da DIO, ministrado pelo professor Felipe Silva Aguiar.  
O objetivo é criar um **dashboard de vendas no Excel** para analisar assinaturas do Xbox Game Pass, transformando dados brutos em informações visuais úteis para a tomada de decisão.

## 📊 O que foi feito
- Organização da base de dados de assinaturas.
- Criação de tabelas dinâmicas para responder perguntas de negócio.
- Construção de um dashboard com indicadores e gráficos.

## 🔑 Perguntas de Negócio Respondidas
1. Faturamento total por tipo de plano (Core, Standard, Ultimate).  
2. Distribuição de assinaturas por periodicidade (Mensal, Trimestral, Anual).  
3. Percentual de assinaturas com auto-renovação ativada vs. desativada.  
4. Ticket médio por cliente considerando planos e adicionais.  

## 📂 Estrutura
- `base.xlsx` → dados brutos.  
- `dashboard.xlsx` → dashboard final.
